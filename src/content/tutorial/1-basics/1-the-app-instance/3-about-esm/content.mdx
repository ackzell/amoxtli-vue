# About ESM

Just like [in the official docs](https://vuejs.org/guide/quick-start.html#using-the-es-module-build), we will be making use of the <AvTooltip id="esm">ESM</AvTooltip> flavor to get a hold of Vue.

Note that the `script` tag has now a `type=module`, so we can use the browser ready package.

```file:/index.html showLineNumbers title="index.html" /https://unpkg.com/vue@3/dist/vue.esm-browser.js/ /type="module"/ {"We are importing directly from the module now":7-12}
```
