# Hello yehyecoa-vue!

On the [first chapter of this Basics part](/basics/the-app-instance/intro) you saw what steps we need to take in order for a Vue app to run in the browser. 

This time we'll use the playground I built around the Vue REPL component and forget about the setup, and dive right into Vue itself. At least that is my goal with this.

If you look at the [deployed](https://repl-vuejs.vercel.app) version of the official REPL you can see all the things the component is capable of. I intentionally hid some of the available tabs, like the **Imports Map**, the **tsconfig.json** in the authoring panel and only left the **Preview** visible in the output panel, to hopefully keep you focused on learning the code and not getting distracted (I know I get distracted easily).

I won't dive deep into the code itself, let's officially begin in the next part with all of the _actual Vue_ concepts. But for now, you can play around with the UI if you want.
